# 秋招求职工作台 · Autumn Job Tracker

在自己电脑上找岗位、对照简历、记录投递和跟进反馈。**每天5个岗位直达＋5个精选推荐**，同公司合并，处理过的不重复推送。资料保存在本机。

## 不懂代码，怎么最快用起来？

**Windows用户：[下载最新版本](https://github.com/yizhizhu222/autumn-job-tracker/releases/latest) → 解压 → 双击 `AutumnJobTracker.exe`。不需要安装Python、Git或申请API Key。**

在下载页展开 **Assets**，选择 `autumn-job-tracker-v1.7.1-windows-x64.zip`。不要选“Source code”，那是给使用源码的人准备的。

把整个压缩包解压到可写目录，例如 `E:\求职工作台`，不要在压缩包内直接运行，也不要只拿走exe而丢掉 `_internal` 文件夹。启动后浏览器自动打开看板，保留程序窗口。

## 第一次使用

### ① 导入自己的简历

点击首页 **导入PDF / 文本简历**，选择不超过5MB的PDF或UTF-8文本文件。程序自动保存原文件、提取正文；相同内容复用，原件不会被微调覆盖。到 **本地AI设置** 检查正文，扫描PDF可以手动粘贴。

**新安装的数据是空的**，不会附带作者的个人简历、邮箱或投递记录。

### ② 安装本地AI（只做一次）

1. 下载并安装 [Ollama Windows版](https://ollama.com/download/windows)。
2. 回到工作台文件夹，双击 **setup-ai.cmd**，等待默认模型下载完成。
3. 在看板 **本地AI设置** 中确认 `qwen3:4b` 显示已就绪。

默认模型约2.5GB，首次下载需要网络与磁盘空间；下载后简历分析在本机执行，不收费调用云端API。模型体积参见 [Qwen3 4B官方页面](https://ollama.com/library/qwen3:4b)。运行速度取决于电脑，首次加载会较慢。模型未就绪时仍可使用本地记录和已有资料。

### ③ 开始找岗位

检查简历正文和求职条件，按需设置地域，点击 **更新岗位信息**。

程序检索公开网页，核查JD和来源，再对照实际简历；不会把搜索摘要直接当作真实岗位。可展开“更新说明”查看失败原因。首次没有足够合格岗位时显示缺额，继续收集后续机会。

> 新岗位搜索需要联网；本地查看、记录、统计和已下载模型的分析可以离线使用。关机时不会执行每日任务。

## 每天怎么用

| 页面 / 操作 | 用途 |
| --- | --- |
| 岗位直达 · 最多5个 | 具体JD、来源、网申入口、本地简历与关键资格已核对，适合先申请 |
| 今日推荐 · 最多5个 | 有简历与JD对应依据，展示推荐理由、短板及尚待确认的条件 |
| 查看投递入口 | 打开具体岗位页面；在企业或招聘平台完成真实申请 |
| 我已投递 | 提交成功后登记日期、实际简历和提交依据，整家公司进入跟踪 |
| 今天看完了 | 当天收起整家公司，可撤销；不计入投递数量 |
| 不感兴趣 | 记住不想要的公司、岗位、平台或岗位类型，可恢复 |
| 反馈与建议 | 写一句近况，查看实际投递简历、JD和可核查就业案例支持的建议 |
| 简历与项目 | 按真实JD需求选择项目，给出步骤、成果、验收方式和完成后的简历写法 |

两栏不重复公司；当天清单固定，处理后不补位，刷新不会重置。第二天优先新公司。已投公司不再推荐，只跟踪进展；未投历史公司只有有依据的高匹配岗位可例外，同岗位至少间隔7天。质量不够时不凑数。

来源优先企业官网，其次高校就业网、经过交叉核实的招聘平台和公众号。搜索包含BOSS直聘、猎聘、前程无忧等公开页面；受登录和验证码限制的内容不会绕过，也不保证能读取。

投递次日起，未填写反馈的记录会在首页提醒；等待回复期间每7天再提醒更新。可以自由写感受，但这些文字**不参与录用建议生成**，也不会自动改变招聘进度。案例少或实际简历缺失时直接说明，不编造录用原因和上岸率。

## 简历与邮箱

- 简历只做少量措辞建议，保留结构和个人事实；未完成的项目不会自动写成经历。
- Windows便携包包含PDF读取、AI微调方案与正文导出。**保持原排版的PDF微调导出是源码版的可选功能**，需要额外安装PyMuPDF，无法保持版式时停止导出。
- 在已投记录中可连接QQ/Gmail的IMAP授权码或应用密码，检查登记招聘方的来信标题及可识别垃圾邮件夹。只读，不发送、删除或标记已读。
- 邮箱授权码只在当前程序内存中，重启后需要重新连接。聊天里的邮箱连接不会自动授权本地程序。

## 数据、备份与升级

默认数据在程序旁边的 **data/** 文件夹，网页底部显示真实位置。简历保存在其中的 **resumes/**；投递、反馈、偏好、每日清单等分别保存在本地JSON文件。写入前有备份，并使用临时文件原子替换。

**升级最稳妥的做法：**关闭旧程序 → 备份整个数据目录 → 新版解压到新文件夹 → 通过config.json接入原数据 → 启动并核对页脚路径。不要用新建的空data覆盖旧目录。

已有 `E:\面试` 数据时，将 `config.example.json` 复制为 `config.json`，内容改成：

```json
{"data_dir":"E:/面试"}
```

使用自启动的用户更换安装目录后，在新版里重新设置自启动。重复启动同一版本会打开已有看板；不同目录或版本占用端口时会提示，不会偷偷切换数据。不同端口也不能同时写同一数据目录。

## 常见问题

**打开后没有岗位？** 新安装没有预装真实资料。先导入简历、准备本地模型，再更新；查看更新说明和质量缺额。没有线上面试等关键条件证据的岗位不会进入直达栏。

**AI连接不上？** 打开Ollama后重试setup-ai.cmd，在设置中确认模型名称一致。脚本会检查常见安装位置，不依赖刚安装时尚未刷新的PATH。模型下载失败可以重试。

**网页打不开？** 保留程序窗口，访问 `http://127.0.0.1:18728/`。若提示旧版本或其他数据目录正在运行，先关闭旧程序。不要通过换端口同时修改同一数据。

**为什么数量不足10个？** 两栏各5个是上限。来源不明、JD缺失、岗位过期、缺少简历证据或历史重复都会被排除，不把未经核实的岗位拿来补数。

**为什么今天更新了仍没新岗位？** 当天清单已经固定；已投、看完或排除的名额不补位。新收集的线索留给后续日期。

**能放GitHub Pages吗？** 不能直接把这个程序放Pages运行。GitHub用于下载和更新，程序、文件和本地AI在你的电脑上运行，不需要购买服务器。

**Windows提示未识别的应用？** 当前发布包没有商业代码签名。核对本仓库下载来源和发布页SHA256SUMS.txt，不要关闭系统安全防护。

## 使用源码（可选）

需要Python 3.10或更新版本。[下载Python](https://www.python.org/downloads/)。从 **Code → Download ZIP** 下载、完整解压，在该目录打开终端：

```powershell
python -m pip install -r requirements-ai.txt
python app.py --open
```

Windows也可双击 `start-windows.cmd`。macOS/Linux使用 `python3 app.py --open`，自行安装Ollama后执行 `ollama pull qwen3:4b`。保持排版的PDF微调使用requirements-ai.txt中的可选PyMuPDF组件，请遵守其许可。

已有数据可显式指定：

```powershell
python app.py --data-dir "E:\面试" --open
```

添加或导入自己的岗位库使用页面“更多”菜单；格式参考 [虚构示例](examples/catalog.example.json)。导入追加新岗位，不覆盖历史投递。完整字段和旧版本功能说明见 [历史文档](docs/HISTORY.md)。

## 检查与发布

```powershell
python -m unittest discover -s tests -v
python tools/build_release.py
# Windows开发者构建便携包
python -m pip install "pyinstaller>=6.15,<7"
python tools/build_windows.py
```

源码ZIP使用固定文件清单；WindowsZIP只打包程序和界面，不包含个人数据。发布流程会实际启动exe，验证空白目录、导入简历、重复启动及重启后保存数据，再上传Release及SHA256校验文件。

程序仅监听本机回环地址，不自动向招聘方提交简历。所有对外申请由用户在岗位网页或自己的邮箱完成。
