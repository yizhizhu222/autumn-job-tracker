## 继续保留的边界

- 本地搜索依赖公开搜索页及可访问的招聘页面。公众号、招聘平台可能需要登录、验证码或只提供客户端内容；此时标记失败，不绕过限制，也不承诺每天凑满10个。
- 网页JD由本地模型提取，并校验原文依据；页面变更或模型误读仍可能存在，重要条件需核对原文。
- 来源核查不是企业信用评级；知名平台上的公司不自动视为可靠雇主。
- 简历技能匹配是原文证据筛选，不是录用概率。公开录用案例数量有限，不能推断本次无回复或拒绝原因。
- 队列首次生成即固定。已分配的岗位退出后不补位；升级不会重置当天记录。
- 提示抓取时间预算是停止发起新任务的预算；已经发出的单个网页/模型请求仍受自身超时限制。
- 扫描PDF需要手动粘贴正文；便携版不包含可选的保排版PDF导出组件。
- 系统只在本机运行；不自动投递、不绕过招聘网站登录，不是部署到GitHub Pages的公网网站。

## 复现检查

运行 `python -m unittest discover -s tests -v`。Windows发布构建另执行 `python tools/build_windows.py`，会启动真实exe检查资源、简历导入、重启持久化和重复启动。

发布前还应从GitHub下载最终Windows ZIP，解压到新目录检查，不把开发目录中的个人数据打入发布包。
