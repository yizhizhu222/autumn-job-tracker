# 第一次使用：照着做就可以

## 1. 下载并打开

打开 [下载页](https://github.com/yizhizhu222/autumn-job-tracker/releases/latest)，展开 **Assets**，选择名字包含 **windows-x64.zip** 的文件。适用于64位Windows。

右键压缩包 → **全部解压缩**，放到自己方便找到的位置。进入文件夹，双击 **AutumnJobTracker.exe**。

浏览器会自动打开看板。保留程序窗口；关掉窗口会停止后台服务。以后仍双击这个文件即可，已运行时会打开原来的看板。

## 2. 导入自己的简历

点击首页 **导入PDF / 文本简历**，选择不超过5MB的PDF或UTF-8文本文件。程序自动归档、识别文字，相同内容不会重复归档。打开 **本地AI设置** 检查文字是否完整；扫描版PDF没有文字时可以在这里粘贴正文。

下载包不含作者个人资料。导入后点击更新，会先显示有效的公开岗位池，再继续联网收集。

## 3. 开启本地AI与自动发现岗位

1. 到 [Ollama官网](https://ollama.com/download/windows) 下载并安装Windows版本。
2. 回到刚才解压的文件夹，双击 **setup-ai.cmd**，等待默认模型下载完成。
3. 回到看板 → **本地AI设置**，确认所选模型为 `qwen3:4b`，状态显示已就绪。
4. 确认简历正文、求职条件和地域后，点击 **更新岗位信息**。

首次模型下载约2.5GB，时间取决于网络。[模型信息](https://ollama.com/library/qwen3:4b)。模型下载完成后，简历分析和措辞建议在本机执行；搜索新岗位仍需要联网。不要把邮箱授权码或其他密码填到模型名称中。

## 4. 每天怎么用

- **岗位直达**：最多5个，入口明确、简历已配好；未知条件会提示。
- **今日推荐**：集中展示当天全部6—10个岗位，说明与你简历的对应点和待确认项。
- 同公司合并；直达不足时用推荐补充，首次不足6个会间隔30分钟继续收集。
- 实际在企业网站或招聘平台提交成功后，再点“我已投递”登记。
- “今天看完了”只收起公司，不算投递。已处理名额计入当天数量，补到6个后不反复补位，第二天继续。
- 次日起查看反馈提醒，写一句“暂无消息”也可以；建议依据实际投递简历、JD和公开案例。

## 5. 数据放在哪里

默认在程序旁边的 **data** 文件夹，页面底部也会显示完整路径。备份时复制整个data文件夹。

已有数据需要接入时，将 `config.example.json` 复制为 `config.json`，用记事本改成：

```json
{"data_dir":"E:/面试"}
```

关闭旧程序，再启动新版。不要同时打开两个程序写同一份数据。更新时解压到新目录，通过config.json指向原数据目录；不要把空白data覆盖原记录。

## 遇到问题

- 浏览器未打开：访问 `http://127.0.0.1:18728/`，查看程序窗口是否有错误。
- AI未就绪：先打开Ollama，再运行setup-ai.cmd；模型下载中断可重新运行继续。
- 没岗位：先导入简历并确认模型就绪，再更新；展开“更新说明”检查网络、登录限制或质量缺额。没有核实到10个岗位时不会编造。
- 同一天一直没有新岗位：当天固定清单不会因刷新重新发放；新收集的线索留到后续日期。
- 想开机自动运行：在看板左下角 **开机自启动设置** 开启。开启后需登录Windows，电脑关机时不会执行。
- 下载后安全提示：本项目尚未提供商业代码签名。核对下载来自本仓库及SHA256SUMS.txt，不要关闭系统安全防护。

Windows便携包包含PDF读取，支持AI微调建议和正文导出；保持原排版的PDF微调导出需要使用源码版并安装可选PyMuPDF依赖，见README。
