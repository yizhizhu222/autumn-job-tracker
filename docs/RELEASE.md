## v1.7.1：新手启动与抓取修复

首次使用请选择 **autumn-job-tracker-v1.7.1-windows-x64.zip**，解压后双击 **AutumnJobTracker.exe**，无需安装Python。

1. 在首页导入自己的PDF或文本简历。
2. 需要AI和自动发现岗位时，安装Ollama，双击setup-ai.cmd下载模型。
3. 在AI设置确认模型就绪，点击更新岗位信息。

本次修复：空白岗位库无法给新岗位选简历、重复启动造成端口/数据冲突、网页编码识别、限流退避、抓取缓存与时间预算；新增导入简历和新手引导。

每日5个直达＋5个推荐、公司去重、反馈提醒、原有数据保护继续保留。Windows包支持PDF读取及微调正文；保持排版的PDF导出需源码版和可选依赖。

下载包没有作者的个人简历、投递记录或邮箱资料。更新前备份自己的data文件夹，通过config.json接入原数据，勿用空目录覆盖。

构建流程会先运行测试，再实际启动打包后的程序，验证首次启动、简历导入、重复启动和重启后保留数据。SHA256SUMS.txt提供下载校验。
