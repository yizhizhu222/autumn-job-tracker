## v1.8.0：每日6—10个岗位，项目持续保留

Windows下载 **autumn-job-tracker-v1.8.0-windows-x64.zip**，完整解压后双击 **AutumnJobTracker.exe**。

- 今日推荐集中显示当天全部岗位；直达页筛出入口明确的机会。优先5+5，直达不足时由推荐补充。
- 未确认的面试、薪资和技能缺口会标注，不再把真实岗位整批隐藏；已投、已排除、已看完的公司继续去重。
- 首轮不足6个时，程序运行且每日推荐开启期间每30分钟继续收集。已处理名额计入当天数量，达到最低数量后不反复补位。
- 内置带核查日期、来源和具体JD的公开岗位池，不含用户简历、邮箱或投递记录；网络暂不可用时仍可读取有效资料。
- 项目参考完整岗位需求库，保留实施步骤、交付物、验收、简历写法和个人进度。已有技能可强化成果证据。
- 暂无JD时按专业提供准备方案，并标明等待岗位验证，不虚报覆盖数量或录用率。

首次使用：导入简历，点击更新岗位；需要本地AI时安装Ollama并运行setup-ai.cmd。已有用户升级前备份数据，并连接原数据目录。

网站无法访问或候选全部被排除时仍需继续研究，不会编造岗位。便携版支持PDF读取与文字修改建议，保排版PDF导出仍为源码版可选功能。
